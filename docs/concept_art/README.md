# Last Assembly concept art

This folder contains a four-piece visual direction pack for the current game.
The images are exploratory reference art, not runtime assets. They are intended to guide future map layouts, narrative panels, enemy silhouettes, and finale presentation.

## Visual language

- Near-black industrial steel, wet surfaces, rust, cables, and layered factory infrastructure.
- Cold cyan and teal for powered systems and life support.
- Restrained red for beacon exposure, enemy sensors, and emergency states.
- Human spaces are improvised, warm, and visibly dependent on machinery that may fail.
- Machine designs are modular, plated, asymmetrical, and built from the same factory language as the world.
