# Project Review

## Project

**Name:** Last Assembly

**One Sentence Pitch:** Survive and salavage even as waves of enemies keep coming towards you, dont bite of more than you can handle.


# 1. First Impression
Spend 10-20 minutes using the project without making changes.
- Current map is confusing and too much information is shown to the player on starting; start with a smaller map that expands as the player progresses
- When you shut down the beacon it's game over — this should instead wait for the player to start the beacon again
- No tutorial
- UI contains many overlapping items
- UI is providing too much information at the start of the game
- It's not clear what recall does and how progress is tracked
- didn't see a clear way of unlocking more towers
- no settings on homescreeen or exit game option

# 2. Story
Would I keep reading?
- currently the game only has a story in the readme, the goal is still the same, the player finds and restores a factory to help the settlement, the more of the factory powered the better the settlment but the attacks are stronger, if you over estimate you might send out salvagers and not be able to recall them before the time runs out.


# 3. Does it Have Potential?
Ignoring its current state...
Could this become something great with more work?
- has some bones and there is already tension with the recall button and knowing the waves will not end

# 4. Biggest Problems
- UI is a mess, if this was given to someone who wasn't aware of the game and its systems they wouldn't know what to do.

# 5. Best Parts
What already works well?
- placing towers, seeing how many you can take before shutting down the beacon

# 6. Next Goal
What is the **single most important milestone**?
- the ui must be simplified, show information as more of the factory is unlocked, gate content behind major repairs, only show the next set afterwards

# 7. Content Notes (Optional)
Would this make an interesting YouTube video or livestream?
- I think if the survival angle worked with recalling salvagers it would.
